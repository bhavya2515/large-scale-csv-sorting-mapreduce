Large-Scale CSV Sorting Using MapReduce

A high-throughput MapReduce implementation designed to sort massive CSV datasets efficiently. Splits unbounded files into balanced partitions, processes key extractions in parallel worker Mappers, and merges sorted streams via a K-Way Min-Heap Priority Queue Reducer with \(O(N \log K)\) complexity.

MapReduce 4-Stage Execution Pipeline

01

Input Splitting

Divides raw CSV dataset into \(K\) uniform chunks, preserving headers across boundaries without memory saturation.

02

Parallel Mappers

Worker processes extract the sort column, type-cast comparable keys, and locally order each chunk partition in parallel.

03

Shuffle & Partition

Tracks min/max key boundaries, manages partition buffers, and coordinates stream descriptors for the global merge.

04

K-Way Merge Reducer

A Min-Heap priority queue simultaneously consumes top elements from all \(K\) streams, producing a globally ordered CSV.

College Project Viva Preparation & Key Concepts

Q1: Why doesn't standard Hadoop guarantee global sort with multiple reducers?

Answer: Hadoop's default HashPartitioner assigns records by hash(key) % num_reducers. While each individual reducer output file (e.g., part-00000, part-00001) is locally sorted, keys are scattered across reducers. To achieve a global sort across multiple reducers, Hadoop requires TotalOrderPartitioner, which samples the dataset to define contiguous key ranges (e.g. Reducer 0 handles keys [0–1000], Reducer 1 handles [1001–2000]). In our local Python simulation, global ordering is guaranteed using sorted chunks followed by a K-Way Min-Heap Merge Reducer.

Q2: What is the time complexity of the K-Way Merge Reducer?

Answer: With \(N\) total records and \(K\) chunks, inserting and popping from the Min-Heap takes \(O(\log K)\). Across all \(N\) rows, total merge time is \(O(N \log K)\). Furthermore, space complexity is only \(O(K)\) in memory, because only the current leading element of each chunk file is held in the priority queue, allowing files larger than available RAM to be sorted safely.
